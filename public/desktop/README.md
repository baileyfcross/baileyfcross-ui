# Seasonal desktop assets

seasons-atlas.webp is original AI-generated pixel landscape artwork created for this redesign, converted to WebP for delivery. Four equal regions: top-left spring, top-right summer, bottom-left fall, bottom-right winter. CSS selects a region using 200% background sizing. Icons and botanical ornaments are original code-native SVG.

season-runtime.js is generated by scripts/build-season-runtime.mjs. It is also embedded inline via src/lib/season-boot.ts to select the seasonal palette before first paint. Astronomy Engine is MIT licensed; its required notices remain in generated output and node_modules/astronomy-engine/astronomy.js.
